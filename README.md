# e-plantShopping

## Paradise Nursery Shopping Application

e-plantShopping is a React and Redux Toolkit shopping application
developed for Paradise Nursery.

Paradise Nursery allows users to explore different categories of
houseplants and add them to a dynamic shopping cart.

## Features

- Paradise Nursery landing page
- About Paradise Nursery section
- Product listing page
- Multiple plant categories
- At least six plants in each category
- Plant image, name, description and price
- Add to Cart functionality
- Add to Cart button disables after adding
- Dynamic shopping cart quantity
- Redux Toolkit state management
- Increase and decrease product quantities
- Delete products from cart
- Product subtotal calculation
- Overall cart total calculation
- Continue Shopping functionality
- Checkout Coming Soon message

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- JavaScript
- CSS
